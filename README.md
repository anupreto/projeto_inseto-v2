# 🐜 Insetos API (Backend)

API desenvolvida em PHP para gerenciamento e consulta de dados do projeto Insetos.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** PHP
- **Banco de Dados:** MySQL (XAMPP / MariaDB)
- **Servidor:** Apache (XAMPP)
